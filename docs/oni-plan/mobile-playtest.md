## 验收步骤

- [ ] 横屏进入 Oni，摇杆与右侧动作区均未被地址栏、刘海或圆角遮挡。
- [ ] 左拇指从摇杆区不同位置按下并推动：前后左右和斜向移动连续，松手后立即停止。
- [ ] 按住左摇杆移动，同时右拇指拖动空白视角区：角色移动和转向同时响应；视角拖动不触发拳、腿或跳跃。
- [ ] 同时按住摇杆、拳键和腿键：动作不会互相取消；先松开其中一个指头时，其他输入继续生效。
- [ ] 在拳、腿、闪避按钮上滑出按钮边界再松手：按住动作保持到抬指，之后正确释放；上划特殊技与前推滑铲各触发一次。
- [ ] 系统来电/通知或浏览器触发 `pointercancel` 后，移动、攻击和视角输入全部复位，不残留按住状态。
- [ ] 连续游玩 5 分钟：页面无意外滚动、缩放、文本选中或横竖屏切换；按钮没有明显误触。
- [ ] 返回菜单后再次开始：所有触控输入仍可正常使用。
